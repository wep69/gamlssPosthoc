gamlssPosthoc 0.3.0#

Inferência pós-GAMLSS e visualização científica data-first com ggplot2.

gamlssPosthoc organiza inferência marginal/distribucional e figuras de modelos gamlss/gamlssZadj sem assumir que mu seja sempre a média. A versão 0.3.0 mantém o núcleo de estimandos explícitos da série 0.2 e acrescenta uma camada gráfica desacoplada:

modelo -> distribuição/estimando -> gamlss_plot_data() -> ggplot

Principais capacidades#

  • parâmetros distribucionais múltiplos em escala de resposta ou link;
  • médias, variâncias, quantis e massa exata em zero;
  • distribuições preditivas (densidade, CDF e sobrevivência);
  • quantile fans baseados em quantis da mistura marginalizada;
  • decomposição zero-adjusted em zero, parte positiva e média marginal;
  • forest/estimation plots para diferença, razão, log-razão e mudança percentual;
  • curvas, primeira/segunda derivadas, turning points e ótimo com bootstrap;
  • superfícies bidimensionais de qualquer estimando suportado;
  • observado + mediana/intervalos preditivos;
  • diagnósticos QQ, resíduos-ajustados, density, PIT, worm-style e rootogram;
  • comparação gráfica de modelos por AIC, global deviance, df ou estimandos;
  • autoplot() para classes do pacote;
  • tidy(), glance(), augment() e parameters::model_parameters();
  • Word, LaTeX, flextable e relatórios automáticos;
  • temas científicos, pkgdown, cheatsheet, benchmarks e workflows avançados.

Instalação de desenvolvimento#

install.packages(c(
  "gamlss", "gamlss.dist", "distributions3", "gamlss.inf",
  "ggplot2", "emmeans", "marginaleffects"
))

Exemplo rápido#

library(gamlss)
library(gamlss.dist)
library(gamlssPosthoc)

set.seed(1)
d <- data.frame(
  dose = rep(seq(0, 120, length.out = 10), each = 8),
  trt  = factor(rep(c("A", "B"), length.out = 80))
)
mu <- exp(.4 + .012*d$dose - .00005*d$dose^2 + .15*(d$trt == "B"))
d$y <- rGA(nrow(d), mu = mu, sigma = .22)
fit <- gamlss(y ~ trt + dose + I(dose^2), sigma.formula = ~ dose,
              family = GA, data = d, trace = FALSE)

# 1. parâmetros
plot_gamlss_parameters(fit, "dose", parameters = c("mu", "sigma"), data = d)

# 2. distribuição completa
plot_gamlss_distribution(fit, "trt", type = "density", data = d)

# 3. derivada da média
plot_gamlss_derivative(fit, "dose", order = 1, data = d)

Camada de dados#

Todo gráfico principal pode ser auditado antes da renderização:

pd <- gamlss_plot_data(
  fit, type = "quantiles", x = "dose",
  probs = c(.1, .25, .5, .75, .9), data = d
)
head(pd)

O usuário pode modificar o ggplot retornado normalmente ou construir a figura diretamente a partir de pd.

Diagnóstico antes do pós-hoc#

plan <- gamlss_posthoc_plan(
  fit, estimand = "mean",
  population = "observed",
  uncertainty = "auto"
)
plan
plot(plan)

Nota sobre validação#

A árvore inclui testes testthat, especificações vdiffr, validação matemática independente e scripts de preflight. O source tarball destinado ao CRAN deve ser produzido por R CMD build e aprovado em R CMD check --as-cran num ambiente R real.
