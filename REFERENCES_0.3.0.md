## Archived predecessor relevant to plotting

`gamlss.ggplots` version 2.1-12 documented ggplot2-based GAMLSS diagnostics and fitted-distribution plots. The package was archived from CRAN on 2025-11-28, so it is cited as prior art but is deliberately not a dependency of gamlssPosthoc 0.3.0.

- Documentation index: https://search.r-project.org/CRAN/refmans/gamlss.ggplots/html/00Index.html
- CRAN archive status: https://stat.ethz.ch/CRAN/web/packages/gamlss.ggplots/index.html
